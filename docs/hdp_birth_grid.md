# HDP birth sensitivity: complete decade grid

This is the archived numerical diagnostic behind the summary in
[HDP presets](hdp_presets.md). It holds `startAlpha=0.1`, `kappa=0`, and
200 total beats. Each cell is the production HDP-only birth proposal score
minus the one-cluster baseline score; larger values favor birth. Rows are
`transAlpha` and columns are `gamma`. These are concentration sweeps, not
results for the current named presets. GP, LDS, and alignment scores are
excluded. Values are rounded to two decimal places.

At `transAlpha=1e7`, `gamma=1e-8` and `1e-2` caused optimizer fallback in
both grids. In the 198+2 grid 8 cells are positive; in the 180+20 grid 5
are positive. The large excursions at extreme concentrations should be
regarded as numerical stress-test output, not calibrated birth guidance.
